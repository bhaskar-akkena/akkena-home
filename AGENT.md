# Agent Instructions: Minimalist Editorial Personal Portfolio

## Visual Identity & Aesthetic Core
- **Style:** High-end architectural minimalism, stark monochrome foundation with rare subtle glowing accents.
- **Background:** Deep obsidian black (`#09090b`) with hair-thin glassmorphic structural grids (`border: 1px solid rgba(255, 255, 255, 0.07)`).
- **Typography:** Extreme contrast—oversized crisp titles paired with small, tracked-out uppercase monospace metadata (`tracking-widest font-mono text-xs`).
- **Layout Structure:** Multi-page modular setup (not constrained to single file) using structured bento/editorial grids, wide margins, and refined padding.

## Core Pages & Components
1. **Header / Navigation:** Persistent ultra-thin navbar containing name mark, active section indicator, and navigation links (`/projects`, `/apps`, `/resume`, `/contact`).
2. **Projects & Apps Display:** Image/video preview cards with sleek hover zoom, tech tag chips, and direct external link redirects (`↗`).
3. **Resume Section:** Clean experience timeline with position titles, dates, company badges, and a direct `[Download PDF]` button.
4. **Contact Modal/Page:** Direct email copy-to-clipboard button + mailto redirect, along with clean social links.
